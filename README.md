# Parking-Management-System
A full stack project of a phoenix cohort student


A full-stack parking management application that allows staff to manage parking spaces, record vehicle entries and exits, and collect payments.

## Features

- User authentication (Register / Login)
- Real-time parking space tracking
- Vehicle Entry & Exit
- Automatic parking fee calculation
- Payment collection and history
- Dashboard with live statistics
- Reports

## Tech Stack

**Frontend**
- React + Vite
- React Router
- Tailwind CSS
- Axios
- Lucide React (icons)

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- bcryptjs
